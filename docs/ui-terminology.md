# Web 界面术语规范

本表约束用户可见文案。数据库枚举与算法名可继续用于代码、接口和论文技术章节，但不应直接成为主界面标题。

| 内部术语 | 用户界面用语 | 使用说明 |
| --- | --- | --- |
| OTHER | 其他 / 待确认消费 | 表示证据不足，不表示不重要或可优先削减 |
| A / B / C tier | 优先确认 / 建议确认 / 可暂时保留 | 只表示人工审核顺序 |
| weekly forecast | 消费基线预测 | 解释为保持历史习惯时的消费参考 |
| confidence interval | 可能波动范围 | 不解释为成功概率 |
| LOW / MEDIUM / HIGH risk | 较低 / 需留意 / 较高 | 指历史波动情景风险 |
| goal_priority | 更快接近目标 | 可接受更明显的预算调整 |
| balanced | 兼顾目标与生活（推荐） | V1 默认模式 |
| life_stability | 尽量保持现有生活 | 调整更少，可能更难达到目标 |
| minimum budget | 每周至少保留 | 用户确认的生活底线，不是系统判断的最低生活标准 |
| adjustability | 你能接受的调整 | 必须保持、尽量少调、适度调整、必要时多调 |
| DRAFT | 待确认候选方案 | 不会自动替换执行计划 |
| ACTIVE | 执行中 | 当前有效预算版本 |
| SUPERSEDED | 历史版本 | 只读保留，可追溯 |
| replan | 重新规划 / 动态调整 | 只改变尚未发生的未来预算 |
| infeasible | 按当前条件暂时无法实现 | 同时给出可调整方向，避免把它表现为系统错误 |

金额统一以人民币元显示，接口与数据库继续使用整数分。日期优先显示本地日期；时间戳不得直接以原始 ISO 字符串作为主要文案。
