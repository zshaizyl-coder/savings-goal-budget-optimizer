# 面向储蓄目标的个性化消费预测与动态预算优化系统

本科毕业设计项目。系统计划从微信、支付宝和银行卡账单中构建统一交易数据，以周为主要分析与执行周期，进行个体化消费预测、储蓄目标可行性判断、分类预算优化和滚动再规划。

## 当前状态

当前处于规划基线阶段（阶段 0—2）。阶段 0 工程骨架已建立。真实微信账单尚未在工作区中找到，因此真实 EDA、V1 需求冻结和 `v0.1-planning-baseline` 里程碑尚不能完成。

## 设计原则

- 通用算法框架与个体化参数估计分离。
- 数据结论和实验数字只来自可复现的真实运行结果。
- 优先使用可解释、可复现且适合约 52 周样本量的方法。
- 已发生交易只读；滚动再规划只改变未来预算。
- 真实账单、隐私字段、私有数据库和敏感日志不得进入 Git。
- 测试仅使用脱敏数据或模拟数据。

## 目录

```text
backend/             FastAPI 后端（后续阶段）
frontend/            Vue 3 前端（后续阶段）
data/sample/         可提交的脱敏或模拟样本
data/private/        本地真实数据（Git 忽略）
docs/                项目、需求与设计文档
experiments/         可复现实验代码与非敏感结果
scripts/             数据检查与开发脚本
tests/               自动化测试
uploads/private/     本地私有上传区（Git 忽略）
```

## 隐私提示

请将真实账单放入 `data/private/`。不要把真实姓名、账号、交易对象或完整备注复制到文档、测试、日志或提交信息中。

## 计划技术栈

技术栈目前作为候选方案保留：Vue 3、Element Plus、ECharts、FastAPI、Pandas、NumPy、statsmodels、scikit-learn、SciPy 或 CVXPY、SQLite。最终模型和优化器将在真实 EDA 与后续实验后确定。
